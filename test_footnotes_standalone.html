🦾 Panda Editor - Footnote Tool Test

Testing the new EditorJS inline footnote tool with auto-generated IDs

📋 How to Test

  1. Wait for the editor to load (status message will appear)
  2. Type some text in the editor below
  3. Select a word or phrase where you want to add a footnote
  4. Click the footnote button (fn) in the inline toolbar
  5. Enter a citation in the modal (e.g., "Smith, J. (2023). Research Study.")
  6. Click "Add Footnote" or press Cmd/Ctrl+Enter
  7. You should see a blue numbered marker appear (1, 2, 3, etc.)
  8. Try adding multiple footnotes - they automatically renumber!
  9. Click "Get JSON Data" to see the footnote data structure
